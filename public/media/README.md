# Carpeta de Archivos Gráficos y Multimedia (/public/media)

Esta carpeta almacena los activos gráficos y recursos visuales del sitio web oficial de **Erika Paola Morales Domínguez** (servidos públicamente bajo la ruta `/media/...`).

## Estructura Recomendada

```
/public/media/
├── branding/          # Logotipos, isotipos, favicon y tarjetas OpenGraph
│   ├── em-monogram.svg       # Isotipo vectorial editorial (EM)
│   └── og-preview.svg        # Tarjeta OpenGraph para redes sociales (1200x630)
│
├── profile/           # Fotografías y retratos profesionales
│   └── erika-morales-portrait.jpg (colocar aquí retrato oficial en alta resolución)
│
├── cases/             # Diagramas, capturas y gráficos de proyectos
│   ├── com-amplifier-flow.png
│   └── hsbc-life-rebranding.png
│
└── certifications/    # Insignias y comprobantes gráficos de certificaciones
    ├── hsbc-ai-ambassador.png
    └── scrum-master.png
```

## Especificaciones de Archivos

- **Fotografía de Perfil**: Formato JPG/WebP, proporción recomendada 4:5 o 1:1, resolución mínima 1200px de alto, iluminación neutra o de estudio.
- **Logotipos & Gráficos**: Preferir formato SVG para escalabilidad infinita y nitidez en pantallas Retina.
- **Tarjetas Sociales (OG Image)**: Proporción 1.91:1 (1200x630 px) para visualización óptima en LinkedIn, Twitter y WhatsApp.
